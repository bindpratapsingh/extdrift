extdrift

Behavioural differencing of browser-extension updates — score the change, not the extension.

1 Choose what to analyse

extdrift compares two versions of the same extension — the release already installed and trusted (N) and the update about to replace it (N+1). It runs both in a sealed, offline sandbox and scores what changed. Pick a pair to begin.

Start here · guided demos

Prepared examples on a small built-in extension — one for each result the tool can return. Best if you are seeing this for the first time.

Real published extensions

Genuine updates downloaded from the add-on store (uBlock Origin, Dark Reader, …). These are safe — watch the tool confirm that on real code. Click to choose one.

Real extension + injected attack

A real extension whose update has one known attack added — it steals the browser's cookie jar and uploads it. This is the threat extdrift exists to catch; watch it get flagged. Click to choose one.
