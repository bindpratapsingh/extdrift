extdrift

Behavioural differencing of browser-extension updates. Score the change, not the extension.

Step 1 Two versions of one extension

Version N is the release already installed and trusted. Version N+1 is the update about to replace it. Both slots take a signed .crx, or a .zip / .xpi if that is what you have.

Version Ninstalled
update
→
Version N+1candidate

Both versions are executed in the same sealed sandbox, under the same scripted session bank-login-then-webmail, against identical local pages. About 35 seconds.

Step 2 Execution

Lines prefixed config are settings. Everything else is read back off the run that just happened.
