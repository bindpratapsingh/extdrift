extdrift

Detecting a malicious browser-extension update by what the two versions do, not by what their code looks like.

1 Choose the two versions of the extension

Version N is the release the user already trusts. Version N+1 is the update the store is about to push to them. Either slot takes a bundled sample or a .zip / .crx / .xpi you drop on it.

Version N the baseline
update
Version N+1 the candidate

Both versions are executed in the same sealed sandbox, under the same scripted run bank-login-then-webmail, against byte-identical pages. Takes about half a minute.
